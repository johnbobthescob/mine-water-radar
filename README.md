# WA Mine Water Opportunity Radar

Intelligence service that flags Western Australian mining developments likely to need groundwater investigations, dewatering, pumping, bore drilling or water treatment.

This repository is being built in phases:

1. **Research** — see [RESEARCH.md](RESEARCH.md) (public data sources, licences, competitors, scoring signals).
2. **Plan** — `PLAN.md` (to follow).
3. **Build** — a working v1 that pulls permitted public data and writes a sample weekly digest under `out/`.

**Licence constraint:** DWER Environment Online is not monitored or scraped. v1 uses only permitted public datasets (primarily CC BY 4.0 MINEDEX, mining tenements, WAMEX, and optionally EPBC referrals).
